## 컨셉

**"설정은 한 번, 집은 계속 바뀌어도" (Quietly Home)**

늦은 밤 귀가. 배우자는 이미 잠들어 있다. 현관 앞에서 워치를 한 번 탭하면 —
조명은 **켜지지 않고**(끔 유지 — 밝기 조절 아님), 에어컨은 **내 선호 온도**로
맞춰진다. 배우자의 값이 아니라. 그리고 이사를 가도: 새 집 현관에서 같은 원터치,
같은 내 값 — **재설정 없이. 단, 새 집에 없는 기기·기능은 사유와 함께 보류된다**
(전면 성공 연출 금지 — 데모가 실제로 보이는 것은 이전+보류 병기다).

- 톤: 기존 목업 3번(야간 침실, 따뜻한 어둠)과 같은 결. LG 언어(Effortless).
- 장면 제안: ①현관 앞 워치 탭(늦은 귀가) ②잠든 배우자의 방은 그대로 어두움
  ③(옵션) 이사 박스가 있는 새 집 현관에서 같은 워치 화면
- 워치 화면 요소: "조용한 귀가" 버튼 1개 + "내 온도 22° · 제습 50%" (탭 = 사람이 누른다)
- 제습은 에어컨 제습(습도 50%)이다 — 별도 제습기를 그리지 말 것 (기기 어휘에 없음)
- 부부 표현: 워치 두 개(각자 손목)로 — 한 계정·한 폰 화면으로 묶지 말 것

## 🚫 금지 목록 (하나라도 위반하면 발표 사용 불가)

1. **원격 금지** — 집 밖(차·회사·주차장)에서 제어하는 연출 ❌. 현관/집 근접만
2. **"모든 준비 완료"류 완료 배지 ❌** — 체크리스트+큰 완료 버튼 연출 금지
3. **무조건형 보안·안심 문구 ❌** — "안심 연결"·"안전하게 보호됩니다" 금지
4. **"알아서"·감지·학습 함의 ❌** — 수면 감지, 자동 인식, "집이 알아서",
   "당신을 이해하는" 금지. 항상 **사람이 탭한다**
5. **"anytime, anywhere" ❌** — anywhere는 원격, 원격은 서버
6. **위치·GPS·지도 요소 ❌**
7. **배우자 상태 공유 화면 ❌** — "OO님이 귀가 중" 알림 연출 금지
7-1. **수면 상태 판정·완료 표시 ❌** — 잠든 배우자는 **배경 연출**로만. 워치·앱
   화면에 "수면 중"·"조용한 귀가 완료" 같은 판정/완료 UI가 붙는 순간 감지·상태공유
   주장이 된다 (제품은 배우자가 자는지 모른다 — 그게 셀링포인트다)
8. **LG 공식 로고 단독 사용 주의** — 프로토타입 표기 병기 전제
9. **없는 기기·기능 연출 주의** — TV·커튼·조명 밝기 조절은 우리 데모에 없음.
   쓰면 "비전 컨셉" 라벨 전제

## 온도값 근거 (2026-07-28 리서치, daria 지시 — "26도는 고문")

- 부부 선호값: **귀가자 22° / 먼저 잔 사람 24°** — 코드·테스트·보드 전체 동기화됨
- 국내 여름 가이드: 실내 22~26°C 적정, 습도 40~60% (24°C 이상 시 40% 권장,
  과냉방=냉방병 주의) — [정책브리핑](https://www.korea.kr/news/healthView.do?newsId=148780861)
- 서구 수면 연구(참고): 침실 15.6~19°C(이상 18.3°C), 습도 30~50% —
  [Sleep Foundation](https://www.sleepfoundation.org/bedroom-environment/best-temperature-for-sleep)
- ⚠️ 두 값은 **페르소나의 개인 선호 설정값**이지 우리의 건강 처방이 아니다
  (NFR5 — 웰니스·의료 판단 배제). 이미지에 "최적 수면 온도" 같은 권고 문구 금지

## 2차분 검수 결과 + 재생성 요청 (2026-07-28 파티)

- 판정: 1번(포스터·라운드 워치) ✅ 채택 / 2번(3단 스토리보드) 🔧 조건부 /
  3번(감성·배려) ✅ 채택 — "배우자 상태 공유도 하지 않아요"를 배려 언어로 뒤집은 것 우수
- 재생성 요청 (우선순위 순):
  1. **[최우선] 24° 추가 — 부부 축 복원.** 세 장 전부 22° 단독이라 1순위 변수
     ("같은 집, 두 손목, 다른 숫자")가 죽었다. 최소 한 장에 두 숫자 공존 —
     워치 두 개 나란히 또는 "같은 집, 각자의 온도 — 22°·24°" 카드
  2. [2번] 워치 화면의 **파란 체크 삭제** — 판정·완료 UI 금지(금지 2·7-1). 버튼과 값만
  3. [2번·3번] 워치를 1번과 같은 **라운드 실루엣**으로 통일
  4. 도어락은 배경 연출 유지 — 새 장에서 키우지 말 것 (Q&A 방어: "장면 연출, 제어 대상 아님")
