## 1. 접근면 A — 데모 CLI 장면 (SCR-C01~C07, 실재)

form-factor: 발표장 프로젝터의 **터미널**. 조작 단위 = "명령 한 줄 실행 = 장면 하나"
(발표자 조작, 관객 무조작). 시각 계약: D2Coding 고정폭·18pt 이상(리허설 실측 대기)·장면 간 빈 줄 2.

### 공통 컴포넌트 (전 장면)

| 요소 ID | 요소 | 유형 | 동작·규칙 |
|---|---|---|---|
| CMP-01 | `scene_header` | 텍스트 블록 | 장면 진입 1회 — 번호·제목·겨냥 Pain (accent). **출처 있는 수치만** (P-1 43.4% ✓ / P-3 6.2% ✓) |
| CMP-02 | `transition_row` | 행 단위 출력 | 전이 1건 = 1행, **일괄 덤프 금지**(발표자가 행마다 말을 얹는다). 형식: 기기/전이/판정/Job 대응 |
| CMP-03 | `honesty_footer` | 고정 슬롯 (dim) | 장면 말미 — 시뮬레이터·미측정·범위 한계. **디자인 요소이지 각주가 아니다** |

### 장면별 명세

| 화면 ID | 장면 | 명령 | 겨냥 | 고유 요소·고정 마이크로카피 |
|---|---|---|---|---|
| SCR-C01 | 🌙 야간모드 (절정) | `demo_night.py --offline` | P-1 43.4% | Job 문장 + 전이 4행. 서버 노드 부재가 화면의 주장 |
| SCR-C02 | 재설치 복원 | `demo_reinstall.py --offline` | P-2 | 실측 리뷰 인용 선행 → "참은 게 아니라 개입할 자리가 없다" |
| SCR-C03 | 이사 매핑 | `demo_relocate.py` | P-2 | 이전+보류=전체(누락 0 시각화) → "조용히 버리지 않는다 — 보류에는 사유가 붙는다" |

## 2. 접근면 B — 손목 1장 (SCR-W01, 설계안·미구현)

form-factor: **원형 AMOLED 워치** (260px 원형 기준, 검정 배경 — AMOLED 관례).
장면은 **야간모드 1개만** — 다른 워치 장면을 만들지 않는다.
목업: [wrist-sketch-night.html](ux-designs/ux-thinq-onme-2026-07-28/mockups/wrist-sketch-night.html) (충돌 시 계약 우선).

### 구성 요소 (위→아래)

| 요소 ID | 요소 | 유형 | 내용·동작 | 관련 FR |
|---|---|---|---|---|
| W01-1 | 모드 표시 | 텍스트 (accent) | `🌙 야간모드` — 현재 적용 프로필 상태 | FR-004 |
| W01-2 | 기기 별칭 | 텍스트 (대형, 주 시선) | `안방 에어컨` — **로컬 표시층 전용**(별칭 규칙 아래) | FR-001 |
| W01-3 | 적용 상태 | 텍스트 + ✓ | `바람 약하게 ✓` — 프로필 값 적용 완료 | FR-004 |
| W01-4 | device_ref | 캡션 (watch_dim, 소형) | `d1 — 프로필이 아는 전부` | FR-001 |
| W01-5 | 정직 표기 | 캡션 (dim) | `설계안 — 미구현` · `참조 어댑터 기반 — 실기기 아님` | NFR-003 |

**인터랙션: 없음(글랜스 전용 설계).** 조작 요소를 넣는 순간 "앱을 열지 않아도"가 무너진다.
프로필 일시정지·폐기 진입은 향후 Prototype 단계 설계 대상으로 보류 — 이 장에 창작하지 않는다.

### 별칭 규칙 (확정 설계 — [결정 2026-07-28](../DECISIONS.md))

- "안방 에어컨"은 **이 워치의 로컬 표시층에만 산다** — 프로필·캐리어·이동 경로 진입 금지
  (`FORBIDDEN_KEY_FRAGMENTS`로 코드가 강제 — 구현·테스트됨. 표시층 자체는 미구현)
- 무별칭 폴백 = device_type 한글화("에어컨")
- **이사하면 별칭은 따라오지 않는다** — 옮길 수 없는 게 아니라 옮길 것이 없다.
  재명명이 UX 정합(이사하면 "안방"이 아니게 되므로)
