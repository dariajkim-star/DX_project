## 1. 비교 프레임

RFI Q1~Q7 회신을 아래 축으로 정리한다. **이 단계는 선별이지 순위가 아니다** —
목적은 RFP 초청 대상(2~3사) 결정.

| 축 | 본 축이 거르는 것 | 원천 질의 |
|---|---|---|
| 워치 실장 실적 | "안드로이드 앱 경험"을 워치 경험으로 파는 회신 | Q1 |
| BLE 실측 역량 | 계측 장비 없이 "가능합니다" | Q2 |
| 벤더 격리 설계 | SDK를 코어에 직결하는 습관 (NFR-4 위반 예정자) | Q3 |
| 문서화 성실성 | 측정 보고서 샘플의 환경·편차 기재 여부 | Q6 |
| 규모 적합성 | PoC 규모 대비 과대/과소 조직 | Q4·Q5 |

## 2. 예시 채점 (가상 페르소나 3사)

| 축 | 업체 A (대형 SI) | 업체 B (IoT 전문 부티크) | 업체 C (모바일 에이전시) |
|---|---|---|---|
| 워치 실장 실적 | △ 실적 있으나 하청 수행 | ◎ 자사 수행 2건 | △ 폰 앱 실적을 워치로 제시 |
| BLE 실측 역량 | ○ 장비 보유, 계측팀 별도 | ◎ 스니퍼 보유·샘플 로그 첨부 | ✕ "협력사 통해 가능" |
| 벤더 격리 설계 | △ 표준 아키텍처 문서만 | ○ 어댑터 패턴 사례 제시 | — 무회신 |
| 문서화 성실성 | ○ 형식 완비, 편차 기재 없음 | ◎ 측정 3회·표준편차 기재 | △ 결과 화면 캡처 위주 |
| 규모 적합성 | ✕ 최소 계약 규모가 예산 2배 | ◎ PoC 규모 적정 | ○ 적정 |

**예시 판정**: B·C RFP 초청 (C는 BLE 축 보완 조건부), A는 규모 부적합 사유 통보.

## 3. 이 표의 포인트 (포트폴리오 독자용)

- 축이 **요구사항 문서에서 역산**된다 — NFR-4(벤더 격리)가 비교 축이 되는 것처럼,
  비교표는 요구사항의 파생물이지 독립 문서가 아니다
- "무회신 ≠ 0점" — RFI 단계의 관용([06](06_RFI.md) §4)과 RFP 단계의 엄격
  ([09](09_제안서평가표.md) 필수 요건)을 구분한다
- 문서화 성실성 축은 본 프로젝트 검증 철학의 조달 버전이다 — 편차 없는 측정
  보고는 자기 보고 신뢰도와 같은 급의 신호로 본다
