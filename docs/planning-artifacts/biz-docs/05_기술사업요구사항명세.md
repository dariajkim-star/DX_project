## 1. 기술 명세 (TS)

### TS-1. 프로필 저장 (FR-1)

- 스키마: `PROFILE_SCHEMA.md` 준수 `[실측]` — 키 구조·금지 항목(위치 좌표 등) 포함
- 예산: 키당 4,096B / 총 128KB. **이 값은 시뮬레이터 보수 기준** — 실장 후
  벤더별 실측치로 갱신하되, 실측 전 임의 확장 금지
- 직렬화: 시뮬레이터 PoC `home_profile/storage.py`와 왕복 호환 (기존 프로필
  로드 가능해야 함)

### TS-2. BLE 근접 제어 (FR-2)

- MTU 가정 20B `[실측: 가민 유래 상수 — 포럼발, '측정' 표기 금지]` → 실측 대체
- 근접 판정·릴레이 방어: `home_profile/proximity.py`의 ProximityGuard 로직 이식
- 서버 무경유 검증: 네트워크 차단 환경에서 전 기능 시연 (기내모드 테스트)

### TS-3. 캐리어 어댑터 (FR-3·NFR-4)

- `CARRIER_INTERFACE.md` 준수: 벤더 API는 `carriers/<vendor>.py` 안에만.
  코어 수정 PR은 검수 거부 사유
- 신고 값의 계보 표기: `측정`/`벤더문서`/`설계값`/`미확인` — 혼용 금지

### TS-4. 온보딩·폐기 (FR-4·FR-5)

- 동의 항목 = `LOCAL_CONSENT_SCOPE` 목록과 일치 (초과 수집 = 검수 거부)
- 폐기 절차·복구 시나리오: REVOCATION.md 재현 + 잔여 한계 문서화 의무
