## 4. 투자 판단 프레임 `[가정]`

- **Go 조건**: 설문 마감 시 H2(이사 세그먼트) 또는 H3(맞벌이 세그먼트) 승격
  + 워치 실장 견적이 예산 상한 내
- **No-Go 조건**: 온바디 수용도(문12) 하위 분포 우세, 또는 BLE 실측이
  시뮬레이터 가정(MTU 20B, 4KB/키)을 2배 이상 초과 이탈
- **보류 조건**: 표본 300 미달 시 심의 연기 — 표본 없는 승인은 하지 않는다
