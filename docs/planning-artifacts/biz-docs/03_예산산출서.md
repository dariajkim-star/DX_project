- 공수(M/M)는 시뮬레이터 PoC 실적 기반으로 유추 `[실측 → 가정 변환]`:
  시뮬레이터 13 스토리를 AI 협업 단독 개발로 완료한 실적을, 실기기 환경
  난이도 계수 2.0~3.0을 곱해 팀 개발 공수로 환산 — **계수 자체가 가정**이다
