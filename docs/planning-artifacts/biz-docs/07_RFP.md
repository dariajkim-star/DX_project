# 07. RFP (제안요청서) — ThinQ OnMe 실기기 PoC 외주

> **AI 초안 — 최종 책임은 팀.** 주필 Paige · 부필 Winston · 2026-07-29
> **프레임워크형 문서** — 실제 발송 이력 없음. 실발주 시 법무 검토 후 발송한다.

## 1. 발주 개요

- 과업명: 온바디 홈 프로필 실기기 PoC (워치 실장 + BLE 실측 + 가전 어댑터)
- 기간: 계약 후 4개월 `[가정]` · 예산 상한: [03_예산산출서](03_예산산출서.md) 총액 내
- 계약 방식: 확정 과업 + 검수 게이트별 기성 `[가정]`

## 2. 배경 자료 (제안사 제공)

NDA 체결 후: [01_사업기획서](01_사업기획서.md)(문제 정의 §2),
[04_요구사항정의서](04_요구사항정의서.md), [05_기술사업요구사항명세](05_기술사업요구사항명세.md),
프로토타입 코드 열람. **VOC 원자료는 제공하지 않는다** — 집계표만.

## 3. 과업 범위

[04](04_요구사항정의서.md) FR-1~6 · NFR-1~4 전부. **§5 범위 제외 항목은 제안서에
포함해도 평가하지 않으며**, 멀티 프로필 충돌 해소를 "덤"으로 제안하는 경우
범위 통제 실패 신호로 간주한다 (범위 절제도 평가 항목이다 — [09](09_제안서평가표.md) E-4).

## 4. 제안서 요구 목차

1. 과업 이해 — **우리 문서의 요약 재진술은 감점**, 빠진 리스크 지적은 가점
2. 기술 접근 — TS-1~4 별 구현 방안, 가정과 실측 계획의 구분 명시
3. 팀 구성 — 등급·이력, Q1/Q2형 실적 증빙
4. 일정 — 검수 게이트 3회 이상 포함
5. 견적 — 과업별 분해 ([03](03_예산산출서.md) §2 구조와 대응되게)
6. 위험 관리 — 최소 3건, 각각 탐지 신호와 대응 포함

## 5. 필수 요건 (미충족 시 평가 제외)

- [10_보안준법검토표](10_보안준법검토표.md) §3 필수 항목 전부 "이행 확약"
- 산출물 소유권 발주 팀 귀속 동의 (BS-1)
- 정직 표기 승계 동의 (BS-4) — 측정 없는 수치에 "실측" 표기 시 검수 거부 조항 수용

## 6. 검수 절차

| 게이트 | 시점 | 통과 기준 |
|---|---|---|
| G1 | 1개월 | 워치 실장 — 프로필 저장·로드 왕복, 스토리지 실측 보고서 |
| G2 | 2.5개월 | BLE 제어 — 기내모드(서버 차단) 시연, 지연 실측 보고서 |
| G3 | 4개월 | 통합 — 이사 시나리오 재현, 기존 테스트 426 passed 회귀 확인 |

각 게이트 보고서는 발주 팀 감사 방식(원본 대조 채점, [G_AUDIT_SCORE.md](../../G_AUDIT_SCORE.md)
준용)으로 검수한다 — 수치는 측정 로그가 따라와야 인정된다.
