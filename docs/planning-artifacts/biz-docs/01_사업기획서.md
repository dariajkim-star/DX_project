## 1. 한 문장 정의

**서버·앱이 죽어도, 이사를 가도, 내 집 설정이 나를 따라오는 온바디(스마트워치)
홈 프로필** — ThinQ ON의 정당한 계승("ThinQ ON을 몸에 새기다").

## 2. 문제 정의 — 왜 지금인가

`[실측]` 구글플레이 ThinQ 리뷰 본수집 74,434건, 부정 리뷰 7,625건 토픽 분석:

| Pain | 내용 | 언급률(전체 부정 기준) |
|---|---|---|
| P-1 | 연결 해제·재등록 — 서버·앱이 죽으면 제어 불능 (SPOF) | **43.4%** |
| P-2 | 앱 재설치·공유기 교체·이사 후 설정 휘발 | 1.37% (경쟁 대비 2.0배) |
| P-3 | 개인정보·계정 요구 부담 | 6.2% (정밀 패턴 매칭, LDA 기준 0.5% 병기) |

핵심 통찰: 이는 개별 버그가 아니라 **홈 상태가 클라우드·앱에 종속된 구조**의
문제다. 구조를 바꾸지 않으면 P-1은 재발한다.

`[실측]` 지켜야 할 강점(긍정 리뷰, 평점 5): LG 다기기 호환성 · 원격 조작 편의 ·
원격 모니터링 — 처방이 이 강점을 깨면 안 된다는 제약 조건.

## 3. 제안 솔루션

- **온바디 프로필**: 홈 설정(온도·루틴·기기 상태)을 워치에 저장 — 키당 4,096B
  예산 `[실측: PROFILE_SCHEMA.md §5]`
- **BLE 로컬 제어**: 서버 경유 없이 근접 제어 — SPOF 제거 (P-1 직결)
- **프로필 이주**: 이사·재설치 후 재등록 없이 복원 (P-2 직결, 데모
  `demo_relocate.py`·`demo_quietly.py` 구현 완료 `[실측]`)
- **무계정 로컬 온보딩**: 동의 범위를 로컬 동작에 한정 (P-3 직결,
  `CONSENT_SCOPE.md` `[실측]`)

## 5. 시장 — 정직 표기

시장 규모 수치는 **본 기획서에 싣지 않는다.** MoA 시장 에이전트 산출(글로벌 IoT
1,500억 달러 등)은 검색 도구 없이 생성된 미검증 값으로 판정됐다(G 감사).
실발주 시 조사 필요 항목: 국내 스마트홈 앱 MAU · 워치 보급률 · LG 가전 재구매율.
**시장의 존재 증거로 갈음하는 것**: 경쟁 앱(SmartThings) 대비 ThinQ 평점 열위의
시계열 `[실측: Epic 5 Q3 — 2026-07 ThinQ 1.67 vs SmartThings 4.11]` — 개선 여지가
곧 기회 공간이다.
