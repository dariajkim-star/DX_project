# 09. 제안서 평가표 — RFP 응찰 평가

> **AI 초안 — 최종 책임은 팀.** 주필 John · 검증 Grumbal · 2026-07-29
> **프레임워크형 문서** — 실제 평가 이력 없음. 배점 설계의 근거를 함께 기록한다.

## 1. 평가 절차

1. 필수 요건 심사 (Pass/Fail — [07_RFP](07_RFP.md) §5) → Fail 즉시 제외
2. 기술 평가 (70점) — 평가위원 3인 독립 채점 후 합의, 편차 20% 초과 항목은 재심
3. 가격 평가 (30점) — 최저가 만점 비례식 `[가정 — 실발주 시 조달 규정 준수]`
4. 동점 시: 기술 점수 우선

## 2. 기술 평가 항목 (70점)

| ID | 항목 | 배점 | 채점 기준 (근거) |
|---|---|---|---|
| E-1 | 과업 이해 | 10 | 우리 문서 요약 재진술 = 하위 채점. **우리가 못 본 리스크 지적 = 상위** — 이해의 증거는 반복이 아니라 반박이다 |
| E-2 | 기술 접근 (TS-1~4) | 20 | 가정과 실측 계획의 구분 명시 여부가 배점의 절반 — 구분 없는 "됩니다"는 8/20 상한 |
| E-3 | 실적 증빙 | 15 | 증빙 문서가 따라오는 실적만 인정 — 무증빙 실적 나열은 0 처리 (출처 없는 수치를 세지 않는다는 본 프로젝트 원칙의 조달판) |
| E-4 | 범위 통제 | 10 | 범위 외 항목([04](04_요구사항정의서.md) §5)을 "덤"으로 넣으면 감점 — 절제가 역량이다 |
| E-5 | 일정·게이트 설계 | 8 | 검수 게이트 3회 이상 + 게이트별 산출물 정의 |
| E-6 | 위험 관리 | 7 | 리스크마다 **탐지 신호**가 있는가 — "주의하겠음"류는 0 |

## 3. 가격 평가 (30점)

- 산식: 30 × (최저 응찰가 / 해당 응찰가) `[가정]`
- 저가 덤핑 방어: 예산 대비 60% 미만 응찰은 이행 능력 소명 요구 후 심사
- 견적 분해가 [03_예산산출서](03_예산산출서.md) §2 구조와 대응되지 않으면
  가격 평가 보류 (비교 불능)

## 4. Grumbal 검증 조항 (배점 설계의 자기 방어)

- E-2·E-3·E-6의 공통 원리: **검증 불가능한 주장에 점수를 주지 않는다.**
  이 평가표로 뽑힌 업체는 계약 후에도 같은 기준(G 감사 준용 검수, RFP §6)을
  받으므로, 평가 단계와 검수 단계의 기준 불일치가 없다
- 평가위원 채점표는 항목별 근거 문장 1줄 필수 — 점수만 있는 채점표는 무효
