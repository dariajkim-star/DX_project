## R-5 상세 — 실증 사례 (Grumbal 조항)

이 리스크는 가정이 아니라 **본 프로젝트에서 3회 실제 발생하고 3회 적발된
사건이다** `[실측]`:

1. MoA B 에이전트가 신뢰도 수치에 존재하지 않는 출처를 3회 연속 첨부
   ("내부 데이터 분석, 2023" ×2, "LG ThinQ 사용자 리뷰, 2023" ×1 — 실제 데이터는
   2026-07-21 수집분으로 연도부터 허위)
2. E 에이전트가 리뷰 데이터에 존재하지 않는 인구통계 페르소나를 3회 연속 생성
   (김민수·김영희 — 리뷰 컬럼은 4개뿐, 인구통계 부재)

**대응의 진화**: 매번 사람이 잡는 방식(1~3회차) → 구조적 제거(자기 보고 폐지,
오염 경로 차단 — orchestrator v3.0) → 정량 게이트(G 감사 점수, 원본 대조 채점,
[G_AUDIT_SCORE.md](../../G_AUDIT_SCORE.md) v1.0). 적용 후 첫 실행 전 항목 청정,
종합 97.6점(감점 내역 전건 공개).

**교훈의 조달 적용**: 외주 검수도 같은 원리를 쓴다 — 측정 로그 없는 수치는
인정하지 않는다 (RFP §6, BS-5). AI든 업체든, **자기 보고는 신뢰의 근거가 될 수
없고 원본 대조만이 근거가 된다.**
