## 2. 프라이버시 검토 (P-3 직결)

| # | 검토 항목 | 판정 | 근거 |
|---|---|---|---|
| P-1 | 수집 최소화 — 로컬 동작에 불필요한 동의 요구 없음 | ✅ | LOCAL_CONSENT_SCOPE / NOT_REQUIRED 목록, 테스트 고정 |
| P-2 | 위치 정보 — 스키마 차원 금지 (lat/lon 금지 항목) | ✅ | PROFILE_SCHEMA 금지 목록 |
| P-3 | 서버 보관 — 프로필 원본 서버 미보유 | ✅ | DATA_RESIDENCY |
| P-4 | 생활패턴 학습 — 감지·행태 학습 미수행 ("원터치" 문법) | ✅ | 설계 원칙 (PLAYBOOK 교훈 9) — 사용자 우려 실측(설문 문13-1 ⑤) 대응 |
| P-5 | 설문 개인정보 — 익명, 연락처는 추첨 희망자만 선택 입력, 사용 후 폐기 고지 | ✅ | 설문 안내문 (SURVEY_DEPLOY) |

## 3. 외주 필수 요건 (RFP §5로 역인용)

| # | 요건 | 판정 기준 |
|---|---|---|
| S-1 | 위협 모델 승계 — THREAT_MODEL 방어 항목 실장 + 잔여 한계 갱신 | 미갱신 시 검수 거부 |
| S-2 | 동의 범위 초과 금지 — 온보딩 요구 항목 diff = 0 | FR-4 인수 기준과 동일 |
| S-3 | 원자료 반출 금지 — VOC 원문·설문 응답 원본 미제공 | NDA + 집계표만 제공 |
| S-4 | 벤더 SDK의 개인정보 수집 고지 — 어댑터별 수집 항목 문서화 | 미문서화 시 G2 게이트 불통과 |

## 4. 잔여 한계 (은폐 없이)

- 릴레이 방어의 잔여 한계: THREAT_MODEL §잔여 한계 참조 — 근접 채널의 물리적
  한계는 프로토콜로 완전 제거 불가, 실기기 실측에서 재평가
- 법무 검토 미실시: 본 검토표는 기술적 자기 점검이며 **변호사 검토를 대체하지
  않는다** `[가정 — 실발주 시 법무 검토 필수]`. 개인정보보호법·전기용품 안전
  규제 등 규제 적합성은 조사 필요 항목
