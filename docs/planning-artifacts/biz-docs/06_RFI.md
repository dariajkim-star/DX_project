# 06. RFI (정보요청서) — 워치 실장·BLE 실측 역량 조사

> **AI 초안 — 최종 책임은 팀.** 주필 Paige · 부필 Winston · 2026-07-29
> **프레임워크형 문서** — 실제 발송 이력 없음. 실발주 시 이 틀로 발송한다.

## 1. RFI의 목적 (RFP와의 관계)

발주 전 시장 정보 수집: ①이 과업을 할 수 있는 업체군이 존재하는가
②우리 공수·예산 가정([03](03_예산산출서.md))이 시장 감각과 맞는가
③RFP 요구 수준을 어디에 놓아야 하는가. **RFI는 평가가 아니다** — 회신은
[08_업체비교표](08_업체비교표.md)의 입력이 되지만 점수화하지 않는다.

## 2. 프로젝트 개요 (회신자 제공용)

- 과업: 스마트워치 홈 프로필 실장 + BLE 근접 가전 제어 실측 PoC
- 기술 자산: 시뮬레이터 PoC·스키마·인터페이스 명세 제공 가능
  ([05](05_기술사업요구사항명세.md) — NDA 후)
- 기간 감각: 3~4개월 `[가정]` · 예산 감각: 비공개 (회신 유도 왜곡 방지)

## 4. 회신 요령

- 분량 상한: 질의당 1쪽 — 회사 소개서 첨부 금지 (Q1·Q2 실적으로 갈음)
- 회신 기한: 발송 후 2주 `[가정]`
- 회신 없는 항목은 "해당 역량 없음"으로 간주하지 **않는다** — RFI는 스크리닝이
  아니므로. 단 RFP 초청 대상 선별에는 참고한다
