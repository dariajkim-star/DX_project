# REVIEW_PLAYBOOK — 리뷰 방식 선택 규칙 + 누적 교훈

수립 2026-07-28 (Epic 3·4 회고에서 제도화) · **새 코드/산출물을 만들기 전에 읽는 문서**.
갱신 규칙: 회고에서만 추가·개정한다. HANDOFF는 이 문서를 링크로만 가리킨다(소모품에
영구 규칙을 두지 않는다 — Paige 판정).

## §1. 방식 선택 규칙 — 결함 유형이 방식을 고른다

Epic 3·4 실측: 세 방식의 적발이 겹치지 않았다.

| 걱정되는 결함 | 쓸 방식 | 실증 사례 |
|---|---|---|
| **적대적 입력** (코드 밖에서 오는 거짓말 — 위조 필드·거대 페이로드·경계 위반) | Claude 서브에이전트 (독립 단일 리뷰어) | 3.1: 위조 `routine_count` → 메모리 고갈 DoS |
| **정직성** (코드가 사용자에게 하는 거짓말 — 실패 경로 리포트·항등식 붕괴) | GPT 교차 리뷰 (이종 모델 대조) | 3.2: 하드 실패 시 리포트 거짓 High 2건 |
| **자기기만** (코드가 자기 자신에게 하는 거짓말 — 측정한 척·죽은 방어·거짓 완료) | 파티 (관점 충돌 — Vex "뭘 막아?" × Yui "아무것도") | 4.1~4.4: 4건 전부 이 유형 |

- 자기기만은 단일 시점에서 정의상 안 보인다 — 관점끼리 서로를 대조할 때만 드러난다.
- 낯선 영역의 미지 결함이 걱정되면 독립 서브에이전트가 우선. 이미 아는 결
  (정직 표기 위반)의 재발 점검은 파티가 우선.
- 파티 점검이 정식 리뷰 게이트를 **대체**할 수 있는 조건: 대상이 문서/계약이고,
  결함 축이 기지(旣知)일 때. 신규 코드는 대체 불가 — 방식 표대로 간다.

## §2. 누적 교훈 (회고 승인분만 등재)

### 코드 (Epic 3·4 리뷰에서, HANDOFF_2026-07-23에서 이관)

1. **측정 안 한 값을 측정한 척 리포트에 담지 마라** (파티 Vex+Yui, 4.1)
   하드코딩 리터럴(`account_created: False`·`network_calls: 0`)은 NFR6 자기위반.
   관찰한 것만 리포트에, 구조적 사실은 그렇게 라벨, 증명은 테스트에.
2. **거짓 이중방어(죽은 코드)를 만들지 마라** (파티 Yui, 4.1)
   절대 안 터지는 재검증은 "안전을 추가하는 척하면서 아무것도 안 하는" 코드다.
3. **실패 경로에서도 리포트가 진실해야 한다** (GPT, 3.2)
   하드 실패 시 계상 누락(항등식 붕괴)·잔류 `transferred`(phantom) 금지. `_abort` 패턴.
4. **상한 없는 와이어 정수는 DoS다** (Claude, 3.1)
   `MAX_*` 상한을 **파싱·전개 전에** 강제한다.
5. **"지웠다/안 보냈다"를 보고만 믿지 말고 확인하라** (4.4 자체 테스트)
   erase 성공 보고 대신 **복원 시도로 검증**한다.
6. **검증 하나가 두 주장을 겸하게 하지 마라** (파티 Grumbal, 4.4)
   "복원 불가"와 "잔류 0"은 다른 주장 — 축을 분리해 둘 다 실측.
7. **무한히 자라는 상태가 방어에 기여하는지 확인하라** (파티 Vex+Yui, 4.3)
   죽은 안전망은 지우고 그 계약을 테스트로 고정하는 게 낫다.

### 전 산출물 (2026-07-28 회고에서 추가)

8. **같은 병은 매체를 갈아탄다** — 코드의 자기기만(측정한 척·완료 배지)은 광고
   언어("모든 준비 완료"·"안심 연결"·원격 함의)로 재발한다. 산출물이 늘 때마다
   정직 표기 검사를 같이 이식할 것. (GPT 목업 6장 판정, imports/)
9. **"알아서"는 우리 문법이 아니다** — 감지·학습 함의 어휘는 프라이버시 반박과
   자충한다. 번역은 **"원터치"** ("손목 한 번 — 내 설정대로"). v3.1 문12 교정의 일반화.
10. **라벨 사기 방지의 일반화 = 등급제** — 가설은 죄가 아니다, 가설을 실측인 척이
    죄다. 페르소나는 PERSONA_LADDER(T1 실측/T2 가설+계측기/T3 처방)에 배치돼야
    존재한다. 김민수·김영희 기각 계보.
